Hi,

When hacking scc, I found commit cd2e3788 fails compiling the
following program:
```
struct dummy {
        int a;
        int b;
};

struct dummy const *s;
```

Output:
```
$ ./bin/scc -c test.c
test.c:6: error: expected ';' before 'const'
```

I found commit 0e78d39ed. The commit message says:
```
Another specifiers are not allowed after a struct/unions/enums
```

However, it seems not to be the case. In c99 spec 6.7.1, it seems
the syntax of declaration-specifiers allows mixing *-specifier and
type-qualifier. The compilers 'tcc' and 'gcc -std=c99' can compile
the program. A test[0] in 'tcc' mentioned the following declaration
is valid:
```
struct S const *s2;
```

Therefore, I think it makes sense to allow other specifiers after
a struct/unions/enums. I can work on it if wanted.

[0]: https://repo.or.cz/tinycc.git/blob/1444843fd10120b71cec38f37697162afb5d744b:/tests/tests2/81_types.c

Best,
Zhaoming
