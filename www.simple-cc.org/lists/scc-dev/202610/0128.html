Without this patch, the -o option is ignored when using the -S option.
The file is *always* called `${basename}.s`. With this patch applied,
the assembly file is named according to the -o option. This is
consistent with the behavior of other C compilers (e.g., gcc).

Without this patch:

$ scc -o test.example -c test.c -S
$ ls test.*
        test.c test.s

With this patch:

$ scc -o test.example -c test.c -S
$ ls test.*
        test.c test.example
