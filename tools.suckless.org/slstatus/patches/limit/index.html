limit

Description

This diff makes it possible to highlight values in status bar in a simple and fully customizable way.

Adds a numeric limit and alternate format string to the configuration. When the returned numeric value exceeds the limit, the alternate format is used instead of the default one. Useful for visual alerts such as high CPU/memory usage or low battery, e.g. by changing colors in status bars that support it (such as dwm with color patches).
